# Module: eks-addons

Cluster add-ons installed as a layer on top of the base cluster: the EKS Pod Identity agent, AWS
Load Balancer Controller, EBS CSI driver, Secrets Store CSI driver with the AWS provider,
ExternalDNS, and metrics-server.

**Built in:** PR 5 — `feat/eks-addons`
